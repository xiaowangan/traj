  OCC — 可以用，前提是 pythonocc-core 在你机器上已经装了（师兄的软件能跑说明装了）。但把 OCC 的 Viewer 嵌进你的 Qt
  窗口需要写一套 QtViewer 集成代码，比较麻烦。

  igl — 不适合。igl 是网格处理库（算法向量、曲率），不是可视化库，没有渲染窗口，不能用来显示点。

  mlab (Mayavi) — 可以用，VTK 后端硬件加速，轻松显示几百万个点，API 很简单：
  mlab.points3d(x, y, z, z, colormap='jet', scale_factor=0.5)
  缺点是它弹出自己的独立窗口，不嵌在你现有的 Qt 窗口里（除非做额外的 VTK-Qt 集成）。

  ---
  我的建议：用 PyVista，理由：
  - 同样是 VTK 后端，硬件加速，百万点没问题
  - API 比 mlab 更简洁
  - 可以用 pyvista.BackgroundPlotter 直接嵌进 Qt 窗口

  你想用哪个方向？确定了我再帮你改代码。

  师兄完全不用 matplotlib 显示轨迹，用的是：

  ┌───────────────────┬──────────────────────────────────┐
  │        库         │               用途               │
  ├───────────────────┼──────────────────────────────────┤
  │ OCC (OpenCascade) │ 3D 显示引擎，DisplayShape 显示点 │
  ├───────────────────┼──────────────────────────────────┤
  │ igl (libigl)      │ 三角网格法向量/曲率计算          │
  ├───────────────────┼──────────────────────────────────┤
  │ NumPy             │ 数值计算                         │
  └───────────────────┴──────────────────────────────────┘

  OCC 的显示器是硬件加速的 OpenGL 渲染器，可以轻松显示几百万个点，不会有 matplotlib 那种软件渲染 Z 轴层序崩溃的问题。
