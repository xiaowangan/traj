# 共形振动抛光：第一性原理展开、软件结构与实施路线

这个课题可以明确为：**以真实共形振动抛光过程为研究对象，建立中频误差演化预测模型，用预测结果指导工艺选择，最终把实验数据、预测模型和工艺规则集成为“抛光工艺数据库”软件。**

数据库是最终交付，它决定了研究要形成完整的工程闭环：

**工件初始状态 → 工艺方案 → 中频误差预测 → 实际加工验证 → 数据与规律入库 → 支撑下一次工艺选择。**

其中，中频误差预测虽然是数据库的一项功能，但它是课题的主要科学支撑，需要作为独立研究内容认真展开。

以下给出从物理问题到软件落地的路线。涉及的公式是建议采用的建模框架，具体形式需要结合你的设备和实验验证。

## 一、先把“第一性原理”落实成一个最基本的问题

首先问：

> 为什么同一个抛光工具，在同样的加工时间内，对不同波长、不同方向的表面起伏，会产生不同的去除效果？

这个问题把材料去除、中频误差和共形能力联系起来了。

这里的“从第一性原理出发”，适合理解为：**从运动学、接触力学、工具材料响应和表面演化出发，建立可解释、可标定的模型。**不必一开始就做到磨粒原子尺度仿真。

还要明确：常用的 Preston 去除关系是经验定律，不能把使用它的模型直接称为完全由第一性原理推导出的模型。你的合理路线应是“物理机理约束＋实验辨识”。

已有研究已经针对共形振动抛光提出时域平滑模型和收敛因子，并开展实验验证。因此，创新点需要进一步落在曲面适应性、工况变化、预测可靠性或数据库中的工艺决策上。[共形振动抛光平滑预测研究，2021](https://doi.org/10.1364/AO.424005)

## 二、研究对象必须包含“初始表面”，不能只包含工艺参数

如果模型只有：

> 振幅、频率、压力、加工时间 → 加工后中频 RMS

会存在一个根本问题：**初始中频误差不同，即使工艺参数完全相同，加工结果也可能不同。**

因此，应把预测问题写成：

> 加工后表面状态 = ℱ(初始表面，曲面几何，工具状态，工艺参数，加工时间)

建议至少考虑以下几类信息：

| 类别 | 需要记录或研究的内容 |
|---|---|
| 工件 | 材料、口径、名义曲面、局部曲率 |
| 初始表面 | 面形误差图、中频 PSD、主要波长和方向 |
| 工具 | 尺寸、层结构、材料、厚度、使用及修整状态 |
| 工艺 | 振幅、频率、载荷、转速或进给、加工时间 |
| 环境与介质 | 抛光液配方、温度、供液状态 |
| 实测结果 | 加工后面形、中频变化、低频变化、去除量 |

这里要特别区分**机械振动频率，单位 Hz**，与**表面空间频率，单位 mm⁻¹**。它们通过运动和接触过程发生联系，不能直接等同。

## 三、按四个层次建立物理模型

### 1. 运动学：表面每个位置经历了怎样的相对运动？

例如，理想单轴正弦振动可以写成：

> xᵥ(t) = A sin(2πfᵥt)；vᵥ(t) = 2πfᵥA cos(2πfᵥt)

其中 A 是单边振幅，需要与设备标注的峰峰值区分。

如果设备还有旋转、进给或二维振动，应计算它们在接触面切平面上的相对速度矢量，再取模，不能直接把各项速度大小相加。

这一层输出：

> v_rel(x, y, t)

软件中既要保存设定值，也要尽可能保存实际振动、载荷等测量值。

### 2. 接触力学：为什么波峰可能比波谷去除得更快？

这是研究的核心。

需要研究工具在两个空间尺度上的响应：

- 对名义曲面，工具能否贴合并维持整体接触；
- 对中频起伏，工具是否形成使波峰优先去除的接触压力差。

“共形”不能简单理解成工具对所有尺度的形貌都完全复制。若波峰、波谷始终以同样速率去除，中频起伏就不会衰减。

因此需要建立或辨识：

> p(x, y, t) = 𝒞(曲面与误差形貌，工具结构及材料，载荷，运动历史)

工具的黏弹性、应力分布和工件形貌之间的耦合，已有专门的中频波纹去除研究，可以作为这一层的参考。[黏弹性抛光工具的中频波纹去除机理，2022](https://www.sciencedirect.com/science/article/pii/S0007850622001044)

初期可以用简化接触模型与少量有限元分析解释规律，再把它转化为软件中快速运行的参数化模型；不需要每次预测都调用完整有限元求解。

### 3. 材料去除：压力与运动如何改变表面？

可以从局部 Preston 关系开始：

> r(x, y, t) = K · p(x, y, t) · v_rel(x, y, t)

其中 r 为去除速率，K 为需要标定的有效去除系数。

对多个振动周期平均：

> r̄(x, y) = (1/T) ∫[0,T] K · p(x, y, t) · v_rel(x, y, t) dt

注意，压力与速度可能相关，一般不能直接用平均压力乘平均速度替代。

这一层要通过实验回答：

- 去除量是否近似随时间线性增加？
- 压力或速度变化时，K 是否仍可视为常数？
- 工具磨损、温升、抛光液变化是否导致模型漂移？

文献中已有全口径共形振动抛光的运动实现、去除能力和加工效果研究，可作为基础模型的参照。[共形振动抛光关键技术研究，2021](https://doi.org/10.1016/j.ijleo.2021.166995)

### 4. 表面演化：最终中频误差如何变化？

表面高度满足：

> ∂z(x, y, t)/∂t = −r̄(x, y, t)

但“材料去除得多”不等于“中频误差降低得多”。决定平滑效果的是波峰与波谷之间的**差异去除**。

因此，必须把实际表面相对于名义曲面的误差提取出来，再研究其不同空间频率成分随时间的变化。

## 四、预测模型建议从“单一波纹”逐步走向“真实曲面”

先用简单、可解释的表面误差：

> e(x, 0) = a₀ cos(2πx/λ)

研究在不同工况下，波纹振幅如何变化：

> a(t) = 𝒢(a₀, λ, θ, u, t)

其中 u、q 表示向量，ê 表示误差的傅里叶变换，r̄ 表示周期平均；∫[0,T] 表示积分区间，双积分记作 ∬[区域]。

- λ：波纹波长；
- θ：波纹相对于振动方向的角度；
- u：工艺参数及工具状态。

在小扰动、工况稳定等条件下，可以检验指数衰减近似：

> da/dt = −βa ⇒ a(t) = a₀ exp(−βt)

这里的 β 不能预先假设为统一常数，应研究其与波长、方向、曲率和工艺参数的关系。若实验出现停滞、幅值依赖或新波纹，需扩展模型。

对真实表面，可以进一步建立近似频域关系：

> êₜ(q) = H(q; u, t) · ê₀(q) + ê_new(q)

它把结果分为两部分：

- 原有中频误差经加工后的残余；
- 工艺自身引入的新误差。

**这一项“新误差”不能遗漏，否则软件可能永远预测加工时间越长越好。**

同时，曲率变化、边缘接触和局部工具状态会破坏空间均匀性。全局频域模型只适合经过验证的近似条件；复杂曲面可采用分区模型或空间域演化模型。

软件的第一阶段可先预测“加工后 PSD、中频 RMS 和达标时间”。完整二维误差图需要更多空间信息；仅有 PSD 不能唯一恢复表面形貌。

## 五、先统一测量评价，再做工艺实验

你需要先规定“中频”到底指哪个空间波段。这个范围应根据工件技术要求和检测能力确定，不能直接套用一个通用数值。

若采用归一化正确的二维 PSD，则：

> σ_MSF² = ∬[Ω_MSF] PSD(qₓ, qᵧ) dqₓ dqᵧ

这一指标之外，还应保留方向谱和主要谱峰，避免一个 RMS 数值掩盖方向性条纹。

加工前后的数据必须统一：

- 坐标配准、分析口径和有效掩膜；
- 采样间隔与单位；
- 名义曲面及低阶项去除规则；
- 滤波、窗函数和 PSD 归一化；
- 缺失点与边缘处理方法。

否则模型可能学到的是数据处理差异。

实验可以按以下顺序组织：

| 阶段 | 实验内容 | 主要目的 |
|---|---|---|
| 测量基线 | 同一表面重复测量、重复装夹 | 确定检测重复性与噪声底 |
| 去除标定 | 固定材料和工具，改变载荷、运动及时间 | 辨识去除规律 |
| 平滑辨识 | 不同波长、幅值、方向的波纹，分时加工 | 辨识中频衰减规律 |
| 曲面扩展 | 改变曲率、考察中心与边缘 | 确定模型适用范围 |
| 独立验证 | 新工件或新批次先预测、后加工 | 检验实际预测能力 |

实验设计中尤其值得加入**相近总去除量下的不同工况比较**，这样可以区分“只是去除得更多”和“单位去除量的平滑效果更好”。

同一工件连续加工得到的多个时刻不能随意拆进训练集和测试集。应按工件或批次留出独立验证数据。

## 六、工艺优化要同时控制中频、低频和加工代价

工艺优化可以表述为：

> 在低频面形、粗糙度和允许去除量满足要求的前提下，以尽可能短的加工时间达到中频指标。

例如：

> 在工艺参数 u 和加工时间 t 上求 min t

满足：

> σ̂_MSF(u, t) ≤ σ_target

以及低频面形、粗糙度、去除量和设备范围等约束。

软件输出应包括：推荐参数、预计加工时间、预测结果、可信范围和适用条件。对于超出已验证范围的方案，应明确标注“外推预测”，不能显示成已验证工艺。

## 七、“抛光工艺数据库”要存储完整工艺案例与证据

数据库的核心记录可以定义为：

> **一件工件在某一确定初始状态下，使用某一工具和工艺执行一次加工，并获得一组可追溯的检测结果。**

建议形成以下模块：

| 模块 | 内容与作用 |
|---|---|
| 工件与工具库 | 材料、曲面、工具结构、使用状态 |
| 工艺实验库 | 参数设定、实际运行记录、环境及异常 |
| 检测数据库 | 加工前后原始面形、PSD、评价配置及结果 |
| 模型库 | 模型版本、标定数据、参数、适用范围、验证误差 |
| 预测与优化 | 预测加工结果，比较候选工艺，给出参数建议 |
| 案例检索与回填 | 查找相似工况，将实测结果与预测比较并归档 |

**原始面形数据一定要保存，不能只存 RMS 和图片。**以后评价频段、滤波方法或预测模型发生变化，才能重新计算。

另外，要清楚区分：

- 实测结果；
- 仿真结果；
- 模型预测；
- 已经实验验证的推荐工艺。

数据库最终积累的不只是“某次用了什么参数”，还应包括“这些参数在什么条件下有效，以及证据是什么”。

## 八、实际推进时，先完成一个最小闭环

我建议先限定：**一种材料、一套工具结构、一种明确的曲面或曲率范围、一个目标中频波段。**

第一版闭环只需要做到：

1. 导入加工前面形并自动评价中频误差。
2. 录入真实设备的共形振动工艺参数。
3. 预测加工后中频指标及变化趋势。
4. 完成加工，导入实测结果。
5. 自动比较预测误差，保存完整案例。

之后再扩展曲率范围、工具类型和自动参数优化。数据库的数据结构要从第一轮实验开始建立，软件功能则随模型成熟逐步增加。

你的研究内容可以据此组织为四部分：

1. **共形振动抛光接触与材料去除机理研究。**
2. **中频误差演化建模及预测实验验证。**
3. **面向中频抑制与面形保持的工艺参数优化。**
4. **抛光工艺数据库软件设计与应用验证。**

如果希望题目更明确地体现最终交付，可以考虑：

**《光学曲面共形振动抛光中频误差预测、工艺优化与数据库系统开发》**

下一步最需要明确的是：**工件材料与曲面类型、设备的实际振动及接触形式、现有检测设备，以及已有实验数据。**这四项会直接决定采用全口径还是局部接触模型、预测到哪个层级，以及第一轮实验如何安排。

## 九、当前文件夹的代码识别与能力边界

### 9.1 当前系统是什么

当前项目是 PyQt5 桌面抛光工艺原型：NumPy 负责曲面、轨迹和驻留计算，OCC 提供三维预览，Matplotlib 提供二维面形预览。代码按 `core/`、`workflow/`、`io/`、`ui/` 四个目录整理，入口是项目根目录 `main.py`。八阶段功能入口位于 `polishing/ui/features/`，算法位置和实现边界详见 `docs/architecture.md`。

前五阶段已形成部分可操作链路；复测、验证和归档仍为占位入口。当前工作重点是补齐状态持久化、测量配准、完整口径频谱评价、振动中频模型及实验验证。现有数值基线只说明本地迁移前后输出一致，不代表算法通过了物理或设备验证。

### 9.2 不能照搬 MATLAB 说明的地方

| 项目 | 当前 Python 源码事实 |
|---|---|
| 求解方法 | `_do_dwell_least_squares` 只允许最小二乘；脉冲迭代选项会报暂不可用。底层是 FFT 卷积配合投影及加速迭代，不是直接调用 MATLAB `lsqlin` |
| 模型网格 | `generate_model` 使用 dx、dy 生成网格，不是说明中的固定 501×501 |
| 参数存档 | `_dwell_save_model_config` 保存 JSON，不是 `.mat` |
| 驻留轨迹 | `raster_from_dwell` 当前实现栅形，不能认为已具备 MATLAB 的全部轨迹类型 |
| 区域掩膜 | 求解器从输入面形的有限值区域生成掩膜，没有直接接收建模口径对象 |
| 边缘修饰 | `_do_dwell_modify` 对边缘带加同一调整量，不是说明中的线性渐变 |
| STL 导入 | 当前接入预览显示，不能据此认定已成为驻留求解或任意曲面规划的几何输入 |
| 数据库与中频模型 | 当前已有最大连续有效矩形内的 PSD/中频评价；完整案例持久化、任意掩膜口径 PSD、振动平滑模型或模型版本管理仍未实现 |

以下为源码可定位的问题及待验证风险，不是本轮已经完成的修复。

| 优先级 | 证据位置 | 问题与影响 | 改造后的验收依据 |

| P0 | `_dwell_apply_initial`、`_surface_operation`、`_dwell_select_surface` | 修改网格、处理面形或重新导入后，没有统一清除或标记旧 solution、trajectory、cnc | 修改任一上游输入，受影响产物自动过期，旧 CNC 不可作为当前结果导出 |
| P0 | `generate_cnc` 最后的 `header` 与 `vstack` | `header` 已包含终点抬刀和终点安全点，却整体放在加工 body 之前，导致输出顺序先经过终点再进入加工段 | 输出顺序为起点安全位 → 接近/下刀 → 加工段 → 抬刀 → 安全位；检查导出文件本身的连续顺序 |
| P0 | `raster_from_dwell`、曲面裁剪和预览长线过滤 | 非法点被删除后仍是扁平点列表，缺少跨孔、换行、转移段语义；显示层跳过长线不会改变导出的路径 | 每个路径段显式区分加工、转移、进退刀，预览和导出使用同一分段结果 |
| P1 | `DwellTimeEngine.asphere` 与 `generate_aspherical` | 高阶项分别以减号、加号进入矢高；离轴和坐标表达也各自实现 | 明确系数与坐标约定，用转换适配器迁移；不能不经核对直接合并同名参数 |
| P1 | `solve_bounded_least_squares`、`extend_surface` | 掩膜依赖有限值；延拓填充会使计算辅助区混入真实测量区，负留边也被截为零 | 分开保存物理口径、实测有效区、求解扩展区、轨迹区和评价区；扩展值不参与实测评价 |
| P1 | `read_grid`、`resample_grid` | 三列数据只返回 X 中位间距，后续按等距 X/Y 使用；重采样重建中心坐标 | 验证规则网格及重复点，分别保留 x、y 和 dx、dy，保存原点、朝向、配准变换 |
| P1 | `raster_from_dwell`、`sample_nearest` | 步距按网格倍数取整，但后续仍可使用请求步距换算面积；最近邻返回模型节点 XYZ，会移动原轨迹 XY，并缺少距离上限 | 保存实际采样面积/段长；在查询 XY 处求 z 和法向，对口径外及无法插值点明确拒绝 |
| P1 | `generate_cnc` | 限速后仅重算段行程时间，没有回算真实停留导致的去除偏差；总时间不含全部进退刀段 | 保存理想与可执行速度，分别给出加工时间、辅助时间；用可执行路径重新正向仿真 |
| P1 | 求解器 `objective` 记录逻辑 | 条件使用 `len(objective)` 判断每十次记录：记录数到 21 后可能不再增加；`iterations` 返回记录数而不是真实迭代数 | 用独立迭代计数器，保存终止原因、最终目标值与收敛状态 |
| P2 | 两个 Mixin 的按钮回调 | 大数组计算直接由界面回调调用，未见统一后台任务机制 | 长任务有进度/取消；只在主线程更新 UI；结果按输入版本接收 |

几何边界还需补充检查：根号内非法值被截为零、球面超过单值高度图范围、非球面法向与矢高导数的一致性。这些应建立边界案例确认，不把“能画出来”作为几何有效性的证据。

## 十、结构应该如何设计

### 10.1 先改业务结构，再拆文件

建议以 **工件的一次加工案例** 为主线。顶层流程为：

```text
选择项目/工件 → 加工前检测 → 评价与目标 → 工艺方案
            → 预测与比较 → 执行记录 → 加工后检测 → 验证归档
```

轨迹和驻留是工艺方案的计算工具；工具库、测量库、模型库提供可复用数据。若实际采用全口径振动平滑，应允许不经过扫描驻留求解，直接配置振动、载荷和时长。是否需要轨迹由工艺类型决定。

| 建议页面 | 用户要完成的任务 | 主要结果 |
|---|---|---|
| 项目与案例 | 选工件、浏览加工轮次、追踪当前状态 | 唯一案例与前后状态链 |
| 工件与检测 | 设置名义几何，导入、配准和评价面形 | 可复算的初始状态 |
| 工具与标定 | 选择工具状态，管理打斑和振动去除标定 | 有适用范围的 TIF/模型参数 |
| 工艺方案 | 配置振动平滑或扫描修形，必要时算驻留与轨迹 | 一份固定版本的方案 |
| 预测与比较 | 比较中频、低频、去除量和时间 | 预测报告与适用性说明 |
| 执行与复测 | 记录真实参数、异常和加工后检测 | 实测记录、预测偏差 |
| 数据与模型 | 检索案例、管理评价协议及模型版本 | 可追溯工艺证据 |

界面可继续使用现有 Ribbon 和左右预览布局。页面切换不应成为数据传递机制；所有页面读取同一个项目上下文和明确的业务对象。

### 10.2 当前代码组织

当前项目按便于修改的四个代码目录组织：

polishing/
  core/       曲面、测量、工艺、轨迹、驻留与仿真计算
  workflow/   八阶段状态与界面调用的服务门面
  io/         测量文件、网格、机床输出、授权与资源路径
  ui/         八阶段功能页、窗口、控件、二维/OCC 预览
main.py       桌面应用入口
resources/    图标和样式
data/         示例数据
tests/        固定输入和迁移数值基线

八阶段业务入口集中在 `polishing/ui/features/`；曲面和轨迹算法集中在 `polishing/core/trajectory_*.py`。研究目标和当前实现边界请以项目根目录 `README.md`、`docs/architecture.md` 与 `docs/evaluation_protocol.md` 为准。
### 10.3 最少需要统一的数据对象

| 对象 | 最少字段与规则 |
|---|---|
| `SurfaceGeometry` | 类型、参数版本、口径、坐标系；在给定 XY 求矢高/法向或明确报告不适用 |
| `SurfaceMap` | z、x、y、单位、物理口径、有效掩膜、来源、处理记录、配准变换；名义曲面与误差图分开 |
| `EvaluationProtocol` | 中频波段、低阶去除、窗、PSD 定义、缺失点策略、评价区域、版本 |
| `ToolState` / `RemovalFunction` | 工具结构/磨损、材料、工况、采斑时长、核原点、网格、单位、标定版本 |
| `ProcessPlan` | 工艺类型、参数设定、输入表面状态、工具快照、模型版本；扫描与全口径采用不同配置 |
| `DwellSolution` | 每节点驻留秒数、区域掩膜、预测去除/残差、算法配置、收敛状态、输入指纹 |
| `Trajectory` | 有序段、段类型、XYZ、法向、坐标系、实际采样权重；不要只用无语义的 N×6 数组 |
| `Prediction` | 初始状态、方案版本、指标/谱/可选误差图、适用域、误差或区间、状态 |
| `ProcessRun` | 实际运行参数、日志、开始结束、异常、前后状态、执行方案版本 |

建议内部约定：几何 mm，误差 nm，时间 s，速度 mm/s，振动频率 Hz，角度计算 rad、显示 °。导入时完成显式换算并保留原值；TIF 若为 nm/s，离散节点驻留应为 s；若存驻留密度 s/mm²，求和时必须乘单元面积，二者不能混用。

### 10.4 状态失效设计

每个结果保存“上游数据 ID/哈希 + 参数快照 + 算法版本”。用户修改输入时，保留旧版本供追溯，同时将当前下游标记为待重算。

| 上游变化 | 必须重新生成的结果 |
|---|---|
| 面形、单位、网格、配准、处理流程 | 评价、驻留、相关轨迹、预测、导出 |
| 名义几何、口径、装夹坐标 | 依赖其映射的评价、法向、轨迹、刀位及预测 |
| TIF、工具状态、振动工况 | 对应的驻留或中频预测，以及依赖它们的方案产物 |
| 路径、速度限制或驻留修饰 | 可执行路径、正仿真、时间统计、导出 |
| 评价协议 | 重新评价及判定；原始测量保留，是否重求解取决于目标是否依赖该协议 |

后台任务启动时冻结输入版本；若任务完成时输入已变化，结果只能归到旧版本，不能覆盖当前页面的新结果。

## 十一、把现有驻留模型与中频研究正确连接起来

### 11.1 两类模型分别回答什么

扫描修形的简化离散前向模型：

> Δhᵢ = Σⱼ Bᵢⱼ · τⱼ

其中 Δhᵢ 为第 i 点去除量（nm），τⱼ 为第 j 个位置的驻留时间（s），Bᵢⱼ 为相应位置的单位时间去除率（nm/s）。核不随位置、姿态和曲率变化时，矩阵作用才可近似为平移不变卷积。

> 求 τ，使 ‖W(Bτ − d)‖² + α‖Lτ‖² 尽量小，且 τ_min ≤ τ ≤ τ_max

W 表示评价区选择/权重，d 是目标去除量，L 可表示平滑差分算子，α 是正则化强度。**后面的正则化项是拟议扩展，当前求解器未实现；其必要性应由可执行性和验证数据决定。**

共形振动平滑则研究误差形貌改变接触压力后，波峰与波谷去除差的演化。固定 TIF 能预测宏观去除，并不自动含有随当前波纹变化的接触反馈。对两者的耦合应有实验依据，不能把驻留卷积算出的全频 RMS 改名为“中频预测”。

第一版允许两个独立分支共享检测评价与案例库：扫描修形使用现有 TIF/驻留模型；共形振动使用经辨识的平滑模型。以后再研究先修形后平滑或局部接触联合模型。

### 11.2 中频评价应先于中频预测

对完整等距矩形数据，采用未归一化正向离散傅里叶变换 F，约定双边二维 PSD：

> P(qₓ, qᵧ) = [Δx · Δy / (Nₓ · Nᵧ · U)] · |F(w · e)|²

> U = mean(w²)；Δqₓ = 1/(NₓΔx)；Δqᵧ = 1/(NᵧΔy)

> σ_MSF² ≈ Σ[频点属于 Ω_MSF] P(qₓ, qᵧ) · Δqₓ · Δqᵧ

这里 e 已按固定协议去除均值或低阶项，w 为窗口；e 用 nm、XY 用 mm 时，二维 PSD 单位为 nm²·mm²。该式是所选离散归一化约定：矩形无窗且 e 去均值时，全频积分应与方差一致；加窗后对应窗口加权功率及 U 校正，不能要求它与原始未加窗样本方差逐点相同。

圆口径、缺失点和不规则掩膜不能直接把无效区填零后当成完整矩形测量。先明确采用可靠内接区域、分区谱或经过验证的掩膜处理方法，并报告有效面积、谱泄漏和可信波段。加工前后使用同一协议与有效区域。

验收先用合成面形：已知幅值 a 的正弦波 RMS 为 a/√2；设定已知空间频率和方向检查谱峰。再用重复实测确定噪声底。插值加密不会创造原仪器没有测到的中频信息。

### 11.3 第一版平滑预测与标定

从限定材料、工具、曲率和方向的指数衰减基线开始：

> a(t) = a₀ exp(−βt)

若振幅可可靠测得，多个时刻的 ln(a/a₀) 对时间拟合可辨识 β；单次配对的形式为 β = −ln(aₜ/a₀)/t。低于噪声底、幅值为零或方向不一致的数据不可直接代入。

对条件平稳且新误差与初始误差不相关的简化谱模型，可研究：

> Pₜ(q) = exp[−2β(q,u)t] · P₀(q) + P_new(q,u,t)

平方因子 2 来自 PSD 与幅值平方的关系。存在相关性时还要包含交叉谱项；不能仅凭误差幅值可相加，就认定 PSD 可相加。P_new 是加工引入的新误差，测量噪声需另行表征，二者不能混为一项。

β、P_new、适用范围与预测偏差都来自实验辨识。可以先支持手动参数与演示数据，但必须标记“待标定”，不得输出伪装成实测验证的推荐。2021 年相关研究可作为模型路线参考，不能用摘要代替本设备标定。[原始论文摘要与 DOI](https://pubmed.ncbi.nlm.nih.gov/33983331/)

## 十二、数据库应该如何落地

### 12.1 围绕状态变化建库

关系主线为：

```text
Project → Workpiece → SurfaceState（初始）
                        ↓
                   PlanVersion → Prediction
                        ↓
                   ProcessRun → SurfaceState（加工后）
                                      ↓
                                下一轮加工初始状态
```

一次表面状态可有多次重复检测；一份方案可以做多次预测；一次加工执行引用固定方案版本。预测生成时必须冻结，不能等复测后修改原预测值以缩小误差。

| 实体 | 核心内容 |
|---|---|
| `project`、`workpiece` | 项目、材料、工件编号、几何版本 |
| `surface_state` | 工件、状态序号、前一状态、产生它的加工执行 |
| `measurement`、`artifact` | 状态、测量角色、仪器/波长/单位、时间、原始文件 URI、大小、哈希、格式 |
| `processing_run`、`evaluation` | 输入测量、处理步骤、配置版本、输出文件、频段指标和 PSD |
| `tool`、`tool_state`、`calibration` | 工具定义、使用状态、TIF、工况、标定数据与有效范围 |
| `plan_version`、`process_run` | 设定参数与执行参数分开；保存异常、轨迹、机床配置和日志 |
| `model_version`、`prediction` | 模型参数、标定/验证案例清单、输入快照、适用域和预测结果 |
| `validation` | 预测与复测的关联、同协议比较结果、偏差及判定 |

初期桌面单人使用可采用本地关系数据库加文件仓库这一设计：元数据、外键和索引进数据库，大矩阵与原始二进制文件保存为受管理附件。重点是事务、迁移和备份恢复，不是先选复杂的网络服务。

导入附件时先校验文件并写入临时位置，成功后建立正式引用；处理失败不能留下看似完整的案例。归档/备份必须同时包含数据库与附件，并做一次恢复验证。原始测量不可原地覆盖，处理产生新版本。

### 12.2 入库不是自动学习

每次复测自动计算偏差并形成候选校准数据；只有经过数据质量审核、按工件/批次分组验证后，才发布新模型版本。旧模型及其预测继续保留。

案例检索先按材料、工艺类型、工具结构/状态、曲率范围、初始频谱和目标筛选，再比较效果。数据不足时返回相似案例及缺失信息，不能仅按“压力接近”给出确定性推荐。

历史资料先整理清单，至少补充：文件类型、工件 ID、加工轮次、前测/后测/打斑角色、采样间隔、数值单位、检测日期、关联工况。无法确认的字段标“未知”，未配对的数据可入文件库，但不能直接入训练集。

## 十三、下一步按什么顺序推进

### 13.1 优先级与交付物

| 阶段 | 具体工作 | 完成标准 |
|---|---|---|
| A：可信计算基线 | 明确单位/坐标、保存一组基准输入；处理 CNC 顺序、状态失效、路径分段等 P0 项 | 已知输入的物理量换算正确；导出次序正确；旧结果不会混入新方案 |
| B：数据契约与项目保存 | 抽出 SurfaceMap、Geometry、Trajectory 和项目状态；把读写与计算移出 Mixin | 不启动 GUI 可计算；关闭重开能恢复同一案例和输入版本 |
| C：评价闭环 | 加前后测量配准、PSD、方向谱和指定频段 RMS；落地 EvaluationProtocol | 合成谱峰/能量验证通过，重复测量得到噪声底，同协议可复算 |
| D：第一轮实验入库 | 选一种材料/工具，完成测量重复性、打斑和分时平滑实验 | 至少一组来源明确的前测—工况—后测案例完整归档；足量重复及留出数据按实际噪声确定 |
| E：基线模型 | 辨识 β，保留新误差项接口，明确适用域；做先预测后加工的独立验证 | 报告预测偏差、失败工况与范围；不能用训练拟合误差代替独立验证 |
| F：方案比较与优化 | 比较候选参数，加入低频、粗糙度、去除量和设备约束 | 推荐方案可追溯到模型版本与实验依据；外推有明确标识 |

**最近一个开发迭代应集中在 A、B、C：先让同一份面形能以明确单位、区域和协议保存并复算，再增加中频预测。**项目/文件入库骨架与评价一起建设，不等预测成熟才建库。

### 13.2 第一轮实验表怎么准备

一行代表一次真实加工执行，关联原始文件而非仅贴图片。分四组字段：

1. 对象：工件 ID、材料、曲率/口径、工具 ID、工具状态、装夹坐标。
2. 前测：原始文件、重复测量编号、仪器波长、XY 间隔、单位、评价协议及初始频谱。
3. 加工：振幅定义、fᵥ、载荷、运动方向、时长、介质与温度、实际测量值、异常。
4. 后测：原始文件、配准结果、同区域 PSD/中频 RMS、低频与去除量、关联预测 ID。

先固定工况做重复性与时间序列，再改变波长、方向或载荷。具体水平、重复次数与留出规模在检测噪声和设备边界确认后确定。没有可靠传感器的数据区分“设定值”和“未测”，不要用设定值伪装实测。

### 13.3 必要的验证清单

- 数据：同一物理面形换单位后指标一致；非等距、重复点、缺失单位有明确处理；原始文件哈希不变。
- 几何：平面、球面及非球面已知点的矢高/法向一致；不合法定义域不能靠截断伪装有效。
- 求解：合成已知去除的正反算、非负和上下界、非对称核方向、掩膜与边缘；数值收敛与物理可执行性分别检查。
- 轨迹：跨孔与换行明确分段，实际点距/面积一致，限速后时间与去除量重新计算。
- 评价：正弦谱峰、方向与能量守恒约定正确，前后采用同区域，重复测量得到可报告噪声底。
- 闭环：导入 → 评价 → 方案 → 冻结预测 → 执行 → 复测 → 验证 → 归档，重开后仍能追溯所有输入。

## 附录：用直白的话理解这次设计

现有软件已经能算“往哪里走”和“每个位置停多久”。下一步需要让它知道：这是哪件工件、当前表面到底是什么状态、用哪套工艺预计改善多少，以及磨完以后预测是否准确。

“共形”表示工具对工件名义曲面的贴合能力，不意味着它对所有细小波纹都完全跟随。平滑依靠波峰与波谷的差异去除，不是单纯把波纹“震平”。“低频、中频、高频”是空间尺度的划分，具体界限由检测能力和光学要求确定。

软件输入的是有坐标、单位和有效区域的测量数据，不是一张普通照片。数据库保存的是“什么初始状态、什么工况、得到什么结果、依据是什么”。新实验先作为证据保存，经过验证后再更新模型；这样积累的经验才可复用。

因此，下一步最有价值的产物是：**一份可信的表面数据对象、一套可重复的中频评价协议、一个可保存重开的加工案例，以及一组能够独立验证预测的前后测量数据。**
