# 光学曲面共形振动抛光软件八阶段流程逻辑链

> 整理日期：2026-09-20  
> 对应课题：《光学曲面共形振动抛光中频误差预测、工艺优化与数据库系统开发》

## 1. 文档目的

本文从实际使用者的角度，说明软件八个流程分别回答什么问题、需要什么输入、内部完成什么工作、输出什么结果，以及这些结果如何共同构成一次完整、可追溯的光学曲面加工案例。

八阶段主流程为：

```text
建档 → 评价 → 规划 → 预测 → 执行 → 复测 → 验证 → 归档
```

这八个阶段不是八个互不相关的功能集合，而是一条围绕“同一件工件、同一次加工”的状态链。

完整业务逻辑应当是：

```text
创建加工案例
  ↓
建立期望曲面 + 导入加工前实测面形
  ↓
按统一协议评价低频与中频误差
  ↓
从工艺资源与标定中选择工具、模型和加工方式，形成候选方案
  ↓
预测各方案的加工结果、时间、风险和适用性
  ↓
在质量、去除量和设备约束下优化并冻结最终方案
  ↓
生成设备可执行的轨迹、工艺参数或 CNC/PATH
  ↓
实际加工并记录真实执行情况
  ↓
导入加工后复测数据
  ↓
比较预测与实测，判断是否达标
  ↓
归档完整案例，成为以后工艺选择的证据
```

前五个阶段解决“加工前决策与执行”，后三个阶段解决“加工后验证与知识积累”。

## 2. 一次加工案例的核心对象

### 2.1 期望曲面

期望曲面描述工件加工完成后希望达到的理论形状，例如平面、球面、非球面、柱面或自由曲面。本文统一使用“期望曲面”这一名称。

它主要回答：

> 工具为了贴着理论曲面运动，应当到达哪个 XYZ 位置，表面法向是什么，工具姿态应该怎样变化？

期望曲面主要决定：

- CNC 的理论 Z 坐标；
- 曲面各点的法向；
- 工具姿态和转轴角度；
- 轨迹在曲面上的几何映射；
- 工件物理口径和有效加工区域。

只有期望曲面时，软件可以生成沿曲面运动的几何覆盖轨迹，但不知道工件实际哪里高、哪里低，因此不能计算有针对性的驻留时间和变速修形轨迹。

### 2.2 加工前实测面形

加工前实测面形描述实际表面相对于期望曲面的偏差：

```text
实际表面 = 期望曲面 + 面形误差
```

它主要回答：

> 当前工件具体错在哪里，哪些位置需要多去除，哪些位置需要少去除，当前中频误差由哪些波长和方向组成？

实测面形主要决定：

- 当前 PV、RMS 和中频 RMS；
- 二维 PSD、方向谱和主要谱峰；
- 目标去除量分布；
- 驻留时间和变速进给分布；
- 共形振动加工前的初始中频状态；
- 加工是否达标的评价基线。

没有加工前实测面形时，软件最多只能生成通用覆盖轨迹或经验工艺卡，不能可靠预测针对当前工件的中频改善，也不能生成真正有针对性的变速修形方案。

### 2.3 抛光斑与去除函数

抛光斑通常是工具在特定条件下定点加工一段时间后得到的实测去除坑。将抛光斑按采斑时间和单位进行处理，可得到单位时间去除函数 TIF。

它主要回答：

> 当前工具在当前工况下，在一个位置停留一秒，大约能去除多少材料，并影响多大范围？

抛光斑不是完整加工方案，也通常不是正式工件加工后的最终结果，而是工具加工能力的标定证据。它必须关联：

- 工具编号和工具状态；
- 工件或标定片材料；
- 压力、转速、振幅、频率等工况；
- 抛光液和环境条件；
- 采斑时间；
- 测量单位、网格和标定版本；
- 适用范围和有效期。

工具磨损或工况改变后，原抛光斑可能不再适用，不能把所有历史抛光斑视为同一去除能力。

### 2.4 轨迹

轨迹描述工具按照什么顺序覆盖工件。需要区分两类轨迹：

1. **几何覆盖轨迹**：只依据期望曲面、口径、行距和轨迹类型生成 XYZ 与法向，回答“工具沿哪里走”。
2. **驻留驱动执行轨迹**：依据实测面形、TIF 和驻留结果，把不同位置的加工需求转换为速度，回答“为了修正当前误差，工具在哪里走慢、在哪里走快”。

几何覆盖轨迹是工艺能力之一；驻留驱动轨迹才是扫描修形方案转换成可执行 CNC/PATH 的关键结果。

### 2.5 工艺方案

工艺方案不是单独一个算法或按钮，而是针对某个确定初始状态，将工具、标定、参数、轨迹、预测和约束组合后形成的一份固定版本。

一份完整方案至少应包含：

- 工件和初始表面状态；
- 加工目标与评价协议；
- 工艺类型；
- 工具及工具状态；
- 采用的 TIF 或共形振动模型版本；
- 振幅、频率、压力、方向、时间等工艺参数；
- 轨迹类型、覆盖参数和速度限制；
- 驻留求解或中频演化预测配置；
- 预测加工后指标、加工时间和可信范围；
- 设备约束和风险说明；
- 方案版本和输入数据指纹。

可以用下面的层次理解当前软件功能与“方案”的关系：

```text
加工能力：能生成栅形/螺旋轨迹，能求驻留，能导出 PATH
标定数据：工具状态、实测抛光斑、振动平滑参数
具体方案：针对某件工件选定以上能力和数据，并形成确定参数与预测结果
执行文件：把已确认方案转换成设备可以执行的文件
```

### 2.6 CNC/PATH

CNC/PATH 是已确认工艺方案的设备表达，不是方案本身。

对于扫描驻留加工，执行文件可能包含：

```text
X  Y  Z  工具姿态角  进给速度
```

对于全口径共形振动加工，执行结果可能主要是：

- 装夹位置和工具姿态；
- 预压力；
- 振幅和机械振动频率；
- 振动方向；
- 主轴或附加运动参数；
- 加工时长；
- 进退刀动作；
- 设备控制程序或标准工艺卡。

因此，“执行”阶段更准确的业务含义是“生成并记录可执行加工任务”，CNC/PATH 只是其中一种载体。

## 3. 八阶段之外的“工艺资源与标定”

“工艺资源与标定”是独立于八阶段主流程的基础模块。它不代表某一次加工必须依次完成的阶段，而是长期维护、可被多个工件和加工案例重复使用的能力库。

它回答：

> 软件当前掌握哪些工具、设备能力、实测标定、机床配置和预测模型？这些资源在什么条件下有效？

建议包含以下内容：

| 子模块 | 管理内容 | 主要输出 |
|---|---|---|
| 工具库 | 工具编号、结构、材料、尺寸、磨损和修整状态 | 可选择的 `ToolState` |
| 抛光斑/TIF 标定 | 原始打斑、采斑时间、工况、单位、去除函数和验证结果 | 有版本和适用范围的 TIF |
| 设备能力 | 振幅、频率、压力、转速、速度、行程、姿态和轴限位 | 可供规划和优化使用的约束 |
| 机床配置 | 坐标系、姿态约定、PATH 格式和控制器后处理器 | 可执行文件生成规则 |
| 模型库 | 驻留模型、共形振动中频模型、参数、验证误差和适用域 | 可供预测调用的模型版本 |
| 评价协议 | 中频频段、PSD 定义、去低阶、窗口、缺失点和评价区域 | 可复算的评价协议版本 |
| 标定记录 | 标定日期、实验数据、操作者、环境和质量审核状态 | 可追溯的标定证据 |

它与八阶段的关系是：

```text
                         工艺资源与标定
                    ┌────────┼────────┐
                    ↓        ↓        ↓
建档 → 评价 → 规划 → 预测 → 执行 → 复测 → 验证 → 归档
```

资源在逻辑上是规划、预测和执行的前提，但不应被设置成每次加工都要重复完成的一道顺序步骤。用户只在增加工具、重新打斑、设备能力变化、模型更新或标定过期时维护它。

需要明确区分两种动作：

```text
导入、处理、验证并保存一个抛光斑
→ 工艺资源与标定

在当前工件的候选方案中选择某个 TIF 版本
→ 规划
```

当前功能应按下列原则重新归属：

| 当前功能 | 建议归属 |
|---|---|
| 工具定义、工具状态和磨损记录 | 工艺资源与标定 |
| 抛光斑导入、TIF 提取和标定版本保存 | 工艺资源与标定 |
| 设备极限、机床坐标和后处理器 | 工艺资源与标定 |
| 当前工件选择工具和 TIF | 规划 |
| 当前工件设置压力、振幅、频率和候选时间 | 规划 |
| 当前工件设置轨迹类型、行距和方向 | 规划 |
| 驻留求解和中频演化计算 | 预测 |
| 变速执行轨迹和 CNC/PATH | 执行 |

## 4. 八阶段总览

| 阶段 | 核心问题 | 主要输入 | 内部工作 | 主要输出 |
|---|---|---|---|---|
| 建档 | 这是什么工件，现在是什么状态？ | 项目、工件信息、期望曲面、前测原始文件、单位和坐标 | 案例建档、几何建模、测量解析、单位换算、掩膜和预处理 | 工件档案、初始表面状态、期望曲面模型 |
| 评价 | 当前误差是什么，数据是否可信？ | 初始表面、评价协议 | 配准、去低阶、PSD、方向谱、频带指标和噪声检查 | 加工前评价报告 |
| 规划 | 可以采用哪些加工方式和参数？ | 评价结果、目标、资源库中的工具/标定/设备能力和历史案例 | 工艺分支选择、资源选择、候选参数与轨迹配置 | 候选方案集 |
| 预测 | 各方案加工后会怎样，哪个更合适？ | 候选方案、模型版本、初始状态 | 驻留仿真或中频演化预测、约束优化、不确定性和适用性判断 | 推荐方案、预测报告、冻结方案 |
| 执行 | 怎样把冻结方案交给设备并真实加工？ | 冻结方案、机床配置 | 轨迹、速度、姿态、正仿真、后处理和执行记录 | CNC/PATH/工艺卡、实际执行记录 |
| 复测 | 加工后表面实际变成什么样？ | 后测原始文件、前测处理协议 | 单位转换、配准、同区域同协议处理 | 加工后表面状态 |
| 验证 | 预测是否准确，工件是否达标？ | 冻结预测、执行记录、加工后状态 | 预测与实测比较、误差归因、达标和适用域判断 | 验证报告、候选校准数据 |
| 归档 | 这次加工能否完整追溯并供以后复用？ | 全流程数据与附件 | 冻结版本、建立关联、计算哈希、完整性检查 | 只读加工案例、数据库证据 |

## 5. 八阶段详细逻辑

## 5.1 建档：建立工件与初始状态

### 回答的问题

> 这是一件什么工件？期望达到什么曲面？加工前实际是什么状态？

### 用户输入

- 项目、工件编号和加工轮次；
- 工件材料；
- 期望的平面、球面、非球面、柱面或自由曲面参数；
- 外径、内径、矩形尺寸或其他口径；
- 装夹坐标和离轴量；
- 加工前原始测量文件；
- 仪器、测量波长、面形/波前定义；
- 高度单位、坐标单位和采样间距。

### 内部工作

1. 创建项目、工件和本次加工案例，分配唯一标识。
2. 建立期望曲面，计算 XYZ、有效口径和法向。
3. 读取加工前原始测量，不覆盖原始文件。
4. 显式完成单位换算，保留原始单位和换算记录。
5. 建立有效掩膜、物理口径和坐标系。
6. 按需进行裁边、延拓、坏点处理和滤波。
7. 保存每一步处理配置，保证能够从原始数据重新计算。

### 主要输出

- 工件档案和加工案例；
- `SurfaceGeometry`：期望曲面及口径；
- `SurfaceMap`：处理后的加工前误差面；
- 原始测量附件与元数据；
- 初始 `SurfaceState`；
- 数据处理历史和输入指纹。

### 完成条件

- 期望曲面定义有效；
- 面形数据具有明确单位和坐标；
- 有效区域和采样间距明确；
- 原始文件和处理后数据能够追溯。

## 5.2 评价：确定问题和加工目标

### 回答的问题

> 当前工件究竟有什么误差？主要问题在低频还是中频？中频波纹的波长和方向是什么？数据是否足以支持预测？

### 主要输入

- 加工前 `SurfaceMap`；
- `EvaluationProtocol`；
- 目标中频空间频率范围；
- 低阶项去除、窗口、缺失点和评价区域规则。

### 内部工作

1. 检查采样间距、有效尺寸和可评价空间频率范围。
2. 按统一协议去除均值、倾斜或规定的低阶项。
3. 计算 PV、全频 RMS 和低频指标。
4. 计算二维 PSD、中频频带 RMS、方向谱和主要谱峰。
5. 检查无效点、边缘泄漏和测量噪声底。
6. 根据技术要求建立本次加工目标。

### 主要输出

- 加工前评价报告；
- 低频与中频指标；
- 二维 PSD、方向谱、主要波长和方向；
- 数据质量与可信频段说明；
- 本次加工目标及其评价协议版本。

> 二维PSD：功率在二维频率上的分布密度。
> 中频RMS：只取中频段内的功率积分再开方，表示中频成分的波动幅度。

### 完成条件

- 评价协议已经冻结；
- 初始中频指标可以复算；
- 加工目标明确；
- 数据不足时明确标记，不能继续给出伪精确预测。

## 5.3 规划：形成候选加工方法

### 回答的问题

> 针对当前工件，可以使用什么工具、什么加工方式和哪些参数组合？

### 主要输入

- 工件材料、曲率和口径；
- 加工前评价结果和目标；
- 工艺资源与标定中的工具及工具状态；
- 工艺资源与标定中的抛光斑/TIF；
- 工艺资源与标定中的共形振动模型及其适用范围；
- 工艺资源与标定中的设备能力和机床约束；
- 历史相似案例。

### 内部工作

1. 选择工艺类型：扫描驻留修形、共形振动平滑或组合加工。
2. 从资源库选择当前工件使用的工具及工具状态。
3. 选择与材料、工具状态和工况匹配的 TIF 或振动模型版本。
4. 检查工具与期望曲面的贴合性。
5. 为扫描加工设置轨迹类型、行距、覆盖范围和速度范围。
6. 为共形振动设置振幅、频率、压力、方向和候选时间。
7. 根据历史案例和设备范围生成多个候选参数组合。
8. 标记每个候选方案是已验证、范围内插值还是范围外外推。

### 主要输出

- 候选 `ProcessPlan` 集合；
- 工具与标定数据快照；
- 候选轨迹配置；
- 候选振动工况；
- 适用性和风险说明。

### 规划阶段与当前功能的关系

- “工具库、抛光斑标定、设备能力和模型版本”在“工艺资源与标定”中长期维护；
- “规划”只为当前工件选择具体资源版本，不在此处重新建立工具或重复导入标定；
- “轨迹规划”在当前期望曲面上形成候选覆盖策略；
- “贴合校验”检查当前选择的工具是否适合当前期望曲面；
- “工艺参数设置”形成候选工况；
- 上述选择与当前工件、初始状态和加工目标绑定后，形成候选工艺方案。

## 5.4 预测：比较、优化并冻结方案

### 回答的问题

> 每个候选方案预计会把工件加工成什么样？需要多长时间？是否达标？哪个方案最合适？

### 分支一：扫描驻留修形

计算逻辑：

```text
加工前误差面 + 目标去除量 + 实测 TIF
  ↓
求解驻留时间
  ↓
仿真去除量
  ↓
得到预测残差
  ↓
计算加工前后低频/中频指标和预计时间
```

主要模型为：

```text
去除量 = 去除函数 ⊗ 驻留时间
```

该模型主要回答宏观修形和扫描驻留问题，不能直接等同于共形振动中频演化模型。

### 分支二：共形振动中频平滑

计算逻辑：

```text
初始 PSD
+ 曲率
+ 工具状态
+ 振幅、频率、压力、方向和时间
  ↓
不同空间频率和方向的平滑衰减
  ↓
工艺新引入误差
  ↓
预测加工后 PSD、中频 RMS 和达标时间
```

第一版可采用经实验标定的谱演化模型：

```text
P_t(q, θ) = exp[-2β(q, θ, u)t] · P_0(q, θ) + P_new(q, θ, u, t)
```

其中：

- `P_0` 是加工前 PSD；
- `β` 是不同波长、方向、曲率和工况下的平滑能力；
- `P_new` 是加工过程新引入的误差；
- `u` 包括振幅、机械频率、压力、运动方向和工具状态；
- `t` 是加工时间。

> **扫描驻留修形**是通过控制工具在各位置停留多久来改变去除量。当前项目已有的驻留求解主要属于这条路线：依据 TIF 和驻留时间计算去除，再得到预测残差面。要看加工后 PSD，应从这个残差面重新计算。不能把加工前 PSD 直接减去“去除量的 PSD”，因为 PSD 不含相位信息，误差和去除之间的相互作用也不能这样简化。
> **共形振动平滑**关注工具、接触状态和振动如何让不同波长、方向的起伏产生不同去除效果，从而改变中频误差。它需要振幅、机械频率、压力、方向、曲率和工具状态等信息，并要靠实验标定平滑模型。项目文档里讨论的谱演化模型属于这条路线；这项模型目前尚未实现。

> 需要分支，是因为两者依赖的控制量和物理模型不同：**驻留模型**主要描述“工具走到哪里、停多久、去除多少”，**共形振动模型**描述“接触如何随局部起伏变化、不同空间频率如何衰减”。它们可以先各自预测，再研究如何组合；不能把现有驻留计算结果直接解释成共形振动的中频预测。

### 优化目标

推荐方案不能只追求某一个 RMS 最小。合理目标是：

> 在低频面形、粗糙度、允许去除量、工具贴合性和设备能力满足要求的前提下，以尽可能短的加工时间达到中频目标。

优化时应同时报告：

- 预测中频改善；
- 低频面形风险；
- 预计去除量；
- 预计加工时间；
- 模型适用范围；
- 预测区间或历史验证误差；
- 外推风险。

### 主要输出

- 每个候选方案的 `Prediction`；
- 加工后预测面形或 PSD；
- 预测残差和评价指标；
- 推荐方案及推荐原因；
- 用户确认后冻结的方案版本；
- 预测所用输入、模型和评价协议快照。

### 完成条件

- 最终方案已经人工确认并冻结；
- 预测先于实际加工生成；
- 方案适用性和不确定性明确；
- 复测以后不得修改原预测来缩小误差。

## 5.5 执行：生成设备任务并记录实际加工

### 回答的问题

> 如何把冻结方案转换成设备能够安全执行的加工任务？设备实际上执行了什么？

### 扫描驻留加工的内部工作

1. 根据驻留时间生成执行轨迹。
2. 把驻留时间转换成各轨迹段的进给速度。
3. 从期望曲面获得 Z、法向和工具姿态。
4. 加入工具半径、压入量、坐标偏置和安全进退刀段。
5. 按实际限速重新计算加工时间和正向去除效果。
6. 检查跨孔、换行和不连续区域是否正确分段。
7. 通过机床后处理器输出控制器需要的 CNC/PATH。

### 共形振动加工的内部工作

1. 生成装夹、贴合和进退刀要求。
2. 下发或打印振幅、频率、压力、方向和时间参数。
3. 生成需要的固定位置、覆盖运动或辅助轴程序。
4. 记录设定参数与传感器实测参数。

### 主要输出

- 可执行轨迹；
- CNC/PATH 或设备控制文件；
- 共形振动工艺卡；
- 预计加工时间；
- 实际开始、结束和运行时长；
- 实际振幅、频率、压力、速度和温度；
- 操作员、设备、机床配置、日志和异常；
- `ProcessRun`。

### 完成条件

- 执行文件引用冻结方案；
- 机床坐标、姿态、限位和速度检查通过；
- 实际参数与设定参数分开保存；
- 异常和人工修改有记录。

## 5.6 复测：建立加工后表面状态

### 回答的问题

> 实际加工完成以后，工件表面变成了什么样？

### 主要输入

- 加工后原始测量文件；
- 仪器、波长、单位和采样信息；
- 加工前处理协议和评价区域；
- 执行记录。

### 内部工作

1. 导入并保存加工后原始数据。
2. 将加工后测量配准到加工前坐标系。
3. 使用与加工前相同的有效区域、低阶去除、滤波和 PSD 协议。
4. 保存配准变换及处理历史。
5. 建立新的表面状态，并关联产生它的实际加工执行。

### 主要输出

- 加工后 `SurfaceMap`；
- 后测处理与配准记录；
- 加工后 `SurfaceState`；
- 同协议计算的加工后评价结果。

### 完成条件

- 前后测量使用可比较的坐标、区域和评价协议；
- 原始后测数据可追溯；
- 配准质量满足验证要求。

## 5.7 验证：比较预测和实际结果

### 回答的问题

> 工件是否达到目标？预测准不准？偏差来自模型、设备、工具还是测量？

### 主要输入

- 冻结的加工前预测；
- 冻结的工艺方案；
- 实际执行记录；
- 加工后表面状态；
- 同一个评价协议。

### 内部工作

1. 比较预测残差与实测加工后面形。
2. 比较预测和实测的 PV、RMS、中频 RMS、PSD 和方向谱。
3. 比较预计与实际去除量。
4. 比较预计与实际加工时间。
5. 判断是否达到工艺目标。
6. 判断模型输入是否仍处于标定适用范围。
7. 对偏差进行归因，记录工具磨损、参数漂移、装夹、温度、测量噪声等因素。

### 主要输出

- `Validation` 验证报告；
- 达标/未达标结论；
- 中频预测误差；
- 低频保持情况；
- 时间和去除量偏差；
- 失败工况和适用范围说明；
- 候选模型校准数据。

### 完成条件

- 没有加工后复测时，不得标记为验证完成；
- 预测与实测必须采用同一评价协议；
- 训练拟合结果和独立验证结果必须区分。

## 5.8 归档：形成可追溯数据库案例

### 回答的问题

> 这次加工的全部证据是否完整？以后能否查清当时为什么这样加工、实际效果如何，并用于下一次方案选择？

### 主要输入

- 工件与几何版本；
- 加工前后原始测量；
- 数据处理和评价协议；
- 工具状态及标定；
- 候选方案和冻结方案；
- 预测结果和模型版本；
- CNC/PATH、工艺卡和执行日志；
- 验证报告与异常说明。

### 内部工作

1. 检查必需数据和附件是否完整。
2. 计算附件大小、哈希和正式存储位置。
3. 冻结案例版本，避免原始数据被覆盖。
4. 建立工件、表面状态、方案、预测、执行、复测和验证之间的关系。
5. 区分实测、仿真、预测和人工输入。
6. 将合格案例标记为可检索证据，将数据不足案例标记为仅存档。

### 主要输出

- 只读 `archive_record`；
- 可恢复的数据库记录与附件包；
- 可按材料、曲率、工具、初始 PSD、工艺类型和效果检索的案例；
- 可供审核的候选训练/标定数据集。

### 注意事项

入库不等于自动更新模型。新案例应先经过数据质量审核，并按工件或批次进行独立验证，才能发布新的模型版本。旧模型及其历史预测必须继续保留。

## 6. 三类工艺分支

### 6.1 扫描驻留修形

适合处理需要空间选择性去除的面形误差。

```text
期望曲面 → XYZ、法向和姿态
实测面形 → 目标去除量
实测 TIF → 单位时间去除能力
驻留求解 → 各位置驻留时间
轨迹转换 → 各位置进给速度
机床后处理 → CNC/PATH
```

### 6.2 共形振动平滑

主要针对中频误差的频谱演化和整体平滑。

```text
初始 PSD + 曲率 + 工具状态 + 振动工况
  ↓
频率和方向相关的平滑模型
  ↓
预测加工后 PSD、中频 RMS 和新引入误差
  ↓
优化振幅、频率、压力、方向和时间
  ↓
生成振动工艺任务
```

### 6.3 组合加工

可能的组合方式包括：

- 先扫描修形改善低频面形，再共形振动抑制中频误差；
- 先进行中频平滑，再根据剩余低频误差进行扫描修形；
- 对不同区域使用不同工具或工艺。

组合顺序不能仅凭直觉确定，应由实验验证低频、中频、粗糙度、去除量和总时间之间的影响后再纳入正式推荐。

## 7. 数据依赖与状态失效

每个结果都必须记录上游数据版本、参数快照和算法版本。上游发生变化后，旧结果可以保留用于追溯，但不能继续作为当前结果使用。

| 上游变化 | 必须标记失效的当前结果 |
|---|---|
| 加工前面形、单位、网格、掩膜或处理流程 | 评价、候选方案比较、预测、驻留、执行文件、验证、归档 |
| 期望曲面、口径或装夹坐标 | 法向、曲面轨迹、姿态、CNC、相关预测、验证、归档 |
| 评价协议或目标中频频段 | 评价、达标判断、候选方案比较和验证 |
| 工具状态、抛光斑或标定 | 驻留预测、方案推荐、执行文件、验证、归档 |
| 振动参数或中频模型版本 | 共形振动预测、推荐方案、执行任务、验证、归档 |
| 驻留结果、轨迹或速度限制 | 正仿真、加工时间、CNC/PATH、验证、归档 |
| 加工后复测 | 验证和归档 |
| 验证结论 | 归档状态和案例可复用等级 |

## 8. 数据库主线

数据库不应只是最后一步录入几个数值，而应从创建加工案例时就开始管理状态和版本。

建议关系主线为：

```text
Project
  ↓
Workpiece
  ↓
SurfaceState（加工前）
  ↓
PlanVersion → Prediction
  ↓
ProcessRun
  ↓
SurfaceState（加工后）
  ↓
Validation
  ↓
ArchiveRecord
```

数据库保存的核心知识不是“某次压力是多少”，而是：

> 某件工件在某个确定初始状态下，使用某个工具状态、标定版本和冻结工艺方案执行加工，预测结果是什么，实际结果是什么，预测偏差是多少，这些参数在什么条件下有效。

## 9. 当前软件与目标系统的对应关系

当前软件已经具备或部分具备：

- 期望曲面建模；
- 加工前面形导入和基础处理；
- PV、全频 RMS 等基础评价；
- 工具设置和简化贴合校验；
- 抛光斑导入与 TIF 处理；
- 多类几何轨迹规划；
- 有界最小二乘驻留求解；
- 预测去除量和残差；
- 变速轨迹、工具姿态和 PATH 输出；
- 八阶段界面入口和状态失效框架。

当前前五阶段已经形成以下界面内链路：

```text
期望曲面建模
  → 加工前实测面形
  → 评价
  → 工艺条件与工具选择
  → 抛光斑/TIF
  → 确认候选方案
  → 驻留预测
  → 执行与 CNC/PATH
```

每个必经功能页内部提供“下一步”按钮，并根据当前案例状态控制是否可用；独立几何覆盖轨迹属于可选检查工具，不设置强制下一步；执行是当前已实现链的终点，不跳转到尚未实现的复测。

规划阶段确认后形成 `process_plan`。期望曲面、前测、评价、工艺条件或 TIF 变化时，旧 `process_plan` 以及下游预测、轨迹和 CNC 自动失效。

仍需重点补齐：

- 统一且可持久化的工件/案例对象；
- 加工前后测量配准；
- 二维 PSD、方向谱和指定中频波段 RMS；
- 共形振动中频演化模型；
- 候选方案自动生成和多约束优化；
- 预测可信范围和外推标识；
- 具体机床控制器后处理与正仿真；
- 复测、验证和归档实现；
- 关系数据库、附件仓库和版本管理。

当前“预测”主要是扫描驻留卷积预测，不能直接称为共形振动中频预测；当前“评价”主要是全频统计，不能把全频 RMS 直接称为中频指标。

## 10. 推荐实施顺序

### 第一阶段：可信数据与评价

1. 统一期望曲面、实测面形、单位、坐标和有效区域。
2. 建立可保存和重新打开的加工案例。
3. 实现前后测量配准。
4. 实现 PSD、方向谱和指定频带中频 RMS。
5. 用合成正弦面和重复实测验证谱峰、方向、能量和噪声底。

### 第二阶段：扫描修形闭环

1. 让 TIF 明确关联工具状态和标定工况。
2. 完善驻留求解、轨迹分段和限速后正仿真。
3. 修正并验证 CNC/PATH 进退刀顺序和机床约定。
4. 完成“建档—评价—规划—预测—执行—复测—验证—归档”闭环。

### 第三阶段：共形振动中频模型

1. 固定一种材料、工具结构、曲率范围和中频波段。
2. 开展重复测量、打斑、单一波纹和分时加工实验。
3. 标定 `β(q, θ, u)` 和新引入误差项。
4. 进行先预测、后加工的独立验证。
5. 报告模型适用范围、预测偏差和失败工况。

### 第四阶段：工艺优化与数据库复用

1. 在中频、低频、粗糙度、去除量、时间和设备约束下比较方案。
2. 建立相似案例检索。
3. 区分已验证推荐、范围内预测和范围外外推。
4. 经审核后发布新模型版本，不覆盖历史模型和预测。

## 11. 最终产品定义

最终系统应实现以下用户体验：

> 用户创建一件工件的加工案例，建立期望曲面、加工目标和设备约束，导入加工前实测面形。软件按统一协议识别其低频与中频问题，从“工艺资源与标定”中选择工具状态、实测抛光斑、共形振动模型和设备能力，结合历史案例生成多个候选工艺方案，预测每个方案的加工结果、时间、风险和可信范围，在多项约束下推荐方案。用户确认并冻结方案后，软件生成设备可执行的 CNC/PATH 或共形振动工艺任务。加工完成后导入复测数据，软件自动比较预测与实测、判断是否达标，并将完整证据归档到数据库，支撑下一次工艺选择和模型迭代。

整个课题的核心顺序应保持为：

```text
可信数据
  ↓
统一中频评价
  ↓
中频演化预测
  ↓
多约束工艺优化
  ↓
可执行加工任务
  ↓
复测与独立验证
  ↓
数据库闭环
```

CNC/PATH 是重要工程交付，但课题的主要科学支撑是中频误差评价、共形振动演化预测及其独立实验验证；数据库则把这些研究结果转化为可追溯、可复用的工程知识。
