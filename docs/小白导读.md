# 小白导读：这个项目在做什么、软件怎么用、论文怎么挂钩

> 写给第一次接触本项目的人。不求严谨，求看懂。精确定义请看其他 docs。
> 如果这里和导师、合作方的说法不一致，以他们为准——这份导读是根据代码和文档整理的，不一定全对。

## 1. 一句话

光学镜子表面要抛得极其平整。表面除了**整体弯得不对**（低频），还有一种**细密的波纹**（中频），很难磨掉。
本项目想做的是：**预测**一种叫“共形振动抛光”的工艺能把这些波纹磨掉多少，然后把实验数据、预测模型、工艺规律装进一个**数据库软件**里，下次加工直接查、直接用。

用做菜打比方：
- 镜子 = 一块要擀平的面饼；
- 低频误差 = 饼整体歪了；中频误差 = 饼表面有一圈圈细褶；
- 抛光工具 = 擀面杖；
- 软件 = 菜谱 + 试吃记录：这块饼什么状态、用哪根擀面杖、擀多久、结果和预测差多少。

## 2. 几个必须懂的词

| 词 | 白话 |
|---|---|
| 期望曲面 | 镜子**应该**长什么样（平面、球面、非球面……）的设计图 |
| 实测面形 | 干涉仪量出来的镜子**实际**长什么样，和设计图的差就是“面形误差” |
| 低频 / 中频 / 高频 | 按“起伏有多密”分。很宽很缓是低频，中间间距是中频，很细很密是高频。**中频范围没有通用数值**，由工件要求和测量能力定 |
| 空间频率 | 每毫米起伏几次，单位 周期/mm；波长 = 1/空间频率。和机器振动频率（Hz）是两回事 |
| PSD | 功率谱：把表面拆成不同粗细、不同方向的波，看每种波有多强 |
| 中频 RMS | 只算中频那一段波的“起伏大小”，是本项目的**核心指标** |
| 抛光斑 / TIF | 工具在原地磨一小会儿留下的坑；除以时间就是“磨 1 秒能去多少、影响多大” |
| 驻留时间 | 工具在每个位置停多久。停得久去除得多 |
| 扫描驻留 | 小工具一点点走，靠“停多久”修形状。**软件现在能算的就是这个** |
| 共形振动 | 工具贴着曲面振动，靠波峰比波谷磨得快来平滑中频。**本课题的主角，目前只有骨架** |
| β | 平滑速度：波纹每秒按 exp(−βt) 衰减。**必须靠实验才能得到** |
| 评价协议 | 评价时的规则：中频范围、去不去倾斜、加什么窗、数据是什么单位。**加工前后必须用同一套**，否则比不了 |
| 输入指纹 | 给输入数据算的一串“身份证”。输入变了，指纹就变，用来判断旧预测是否过期 |

## 3. 八个阶段（软件顶部的八个图标）

```
建档 → 评价 → 规划 → 预测 → 执行 → 复测 → 验证 → 归档
 ①      ②      ③      ④      ⑤      ⑥      ⑦      ⑧
```

| 阶段 | 回答的问题 | 现在能做到什么 |
|---|---|---|
| ① 建档 | 这是什么工件？设计图是什么？加工前实际什么样？ | ✅ 建模、导入测量，**新增：自动检查两者对不对得上、读出测量波长** |
| ② 评价 | 现在的误差是什么？问题在低频还是中频？ | ✅ PV/RMS/PSD/方向，**新增：设加工目标** |
| ③ 规划 | 用哪种工艺、什么参数？ | ✅ 扫描驻留；**新增：共形振动（手填参数）** |
| ④ 预测 | 加工完会变成什么样？达标吗？ | ✅ 扫描驻留；**新增：加工后用同一协议重新评价、判达标；共形振动出演化曲线** |
| ⑤ 执行 | 怎么变成机床能跑的文件？ | ✅ 扫描驻留出 CNC/PATH；共形振动没有 |
| ⑥ 复测 | 加工后实际量一次 | ⬜ 占位 |
| ⑦ 验证 | 预测准不准？ | ⬜ 占位（但“预测 vs 实测”的计算函数已写好） |
| ⑧ 归档 | 整个案例存进数据库 | ⬜ 占位；**新增：先有了“保存/打开案例”** |

前五个阶段 = 加工**前**的决策；后三个 = 加工**后**的验证与积累。

另外有一个独立的“工艺资源与标定”：工具、抛光斑、设备能力这类**长期复用**的东西，不属于某一次加工的流程。

## 4. 数据是怎么流动的

```
期望曲面 ──┐
           ├─→ 对齐检查 ─→ 评价协议 ─→ 加工前评价(PSD、中频RMS)
实测面形 ──┘                              │
                                          ├─→ 扫描驻留：TIF + 驻留求解 ─→ 预测残差 ─→ 【同一协议再评价】─→ 达标？
加工目标 ─────────────────────────────────┤
                                          └─→ 共形振动：PSD 演化模型 ─────────→ 中频RMS随时间 ─→ 达标时间
                                                                                     │
                                       保存案例(.polcase) ←─────────────────────────┘
```

关键思想有两个：
1. **前后同一把尺子**：加工前后的评价共用一个协议和同一块采样区域，差别才反映加工本身。
2. **上游一变，下游作废**：改了面形或参数，旧的预测、轨迹、CNC 会自动清空，避免“新数据配旧结果”。

## 5. 怎么用新功能（按顺序点）

1. **建档 → 期望曲面建模**：选口径和面形，点“生成曲面模型”。
2. **建档 → 加工前实测面形**：选 `.dat` 文件。
   - 底部会出现一行**对齐检查**：绿色=通过；黄色=有问题（中心偏了、覆盖不全、尺寸差太多），先查原因。
   - 如果文件头里有波长，会显示“文件头给出测量波长 632.8 nm”。
3. **评价 → 展开“评价当前实测面形”**：
   - 填中频下限/上限（周期/mm）。示例案例的 0.02–0.20 只是**演示值**。
   - **高度单位**：Zygo 的 DAT 通常是“波长数”，确认后选“Zygo 波长数”，波长已预填。**软件不会替你选**。
   - 在“加工目标”里填你要的中频 RMS 上限（可留空）。
   - 点“计算评价结果”。
4. **规划**：选“扫描驻留”（要 TIF 和覆盖预览）或“共形振动”（填 7 个参数，默认值只是演示）→“生成候选方案”。
5. **预测**：
   - 扫描：求解驻留时间 → 自动出“预测后评价”→ 点“查看前后评价对比”。
   - 共形振动：点“预测中频演化”→ 看曲线、最佳时长、达标时间。
6. **保存**：顶部“工具”标签 →“保存案例”。下次“打开案例”，输入会原样恢复、评价自动重算。轨迹和 CNC 不存，要重新生成。

### 看到这些提示怎么办

| 提示 | 意思 | 你该做 |
|---|---|---|
| 高度单位未确认 | 数值没换成 nm，目标也只是“按原数值比较” | 回评价页选对单位 |
| 对齐检查有警告 | 设计图和实测数据对不上 | 检查口径尺寸、离轴量、测量原点方向 |
| 扫描驻留预测只是卷积模型 | 预测很漂亮，但没经实验验证 | 别当结论写进论文 |
| 手动参数、未经实验标定 | 共形振动的 β 是假设值 | 等实验数据，用 `fit_beta` 辨识 |
| 频段上限超过 Nyquist | 网格太粗，看不到那么细的波 | 换更细的网格或降低频段上限 |
| 新误差使中频 RMS 回升 | 磨太久反而引入新波纹 | 取“最佳时长”而不是越久越好 |

## 6. 论文怎么挂钩

合作方只要一篇小论文；你的导师没给具体要求。可行的三条线（由易到难）：

| 方向 | 做什么 | 依赖 | 软件里对应 |
|---|---|---|---|
| **A 评价方法** | 可信的中频评价：单位、区域、噪声底、方向谱，用合成面和重复测量验证 | 几乎不依赖合作方 | 评价协议、`noise_floor`、核心测试 |
| **B 预测模型**（最贴合合作目标） | 标定 β，**先预测、后加工**，再做独立验证 | **需要合作方的实验数据** | 共形振动骨架、`fit_beta`、三方对比 |
| **C 数据库/软件** | 完整案例闭环、可追溯 | 工程工作量 | 案例保存、状态失效、指纹 |

建议：A 打底 + B 做核心 + C 写进毕业论文。**B 能不能成，取决于能不能拿到实验数据**，这一条要尽早问清。

### 需要向合作方 / 导师确认的问题
1. 能不能给加工前后的实测面形、加工工况（振幅、频率、压力、时间）？有没有实测值，还是只有设定值？
2. 设备是全口径共形振动，还是小工具扫描？
3. 测量数据的单位和波长（DAT 里按波长数还是 nm）？
4. 中频的频段范围、验收指标（中频 RMS 多少算合格）？
5. 小论文有没有期刊级别和时间要求？
6. 你是硕士还是博士，离毕业还有多久？

## 7. 这个软件**还不能**做什么（避免被误导）

- 共形振动的预测**没有任何实验支撑**，只是把流程搭好、接口留好。
- 看到“预测中频 RMS 8.9 → 0.5 nm”不要高兴：那是理想卷积模型的结果。
- 复测、验证、归档还没做，所以“预测准不准”现在无法在软件里闭环。
- 期望曲面建模的三维预览比较丑（待改）；CNC 进退刀顺序有已知问题（待改）。
- 镜像或旋转 90° 的测量数据，软件发现不了。

这是面形初测算出来的汇总，按"这块镜子表面有多不平"来理解。

| 名词 | 意思 |
|---|---|
| **检测区域：585 × 456 点** | 实际参与计算的区域，横向 585 个点，纵向 456 个点。边缘无效的点会被排除，只取中间最大的完整矩形。 |
| **采样间距：0.5 × 0.5 mm** | 相邻两个测量点之间隔 0.5 mm。间距越小，能看清的细节越多。 |
| **有效率：99.3%** | 检测区域里有数据的点占 99.3%，其余是坏点或空缺。越接近 100% 越可靠。 |
| **PV：415.28 nm** | 最高点和最低点的高度差，反映最大起伏。nm 是纳米，1 nm 约为头发丝直径的十万分之一。 |
| **RMS：39.802 nm** | 所有点偏离平均面的"平均偏差"（均方根），比 PV 更能代表整体平整程度。越小越好。 |
| **去低阶 RMS：39.791 nm** | 先扣掉整体倾斜和平移，再算的 RMS。因为倾斜多半是装夹造成的，不是镜面本身的问题。 |
| **中频带：0.02–0.2 周期/mm** | 你设的"中频"范围。0.02 周期/mm 表示每 50 mm 起伏一次，0.2 周期/mm 表示每 5 mm 起伏一次。也就是关注起伏周期在 5～50 mm 的误差。 |
| **中频 RMS：8.8042 nm** | 只看上面这个频段的误差有多大。这是共形振动要处理的对象，也是加工目标里"中频 RMS 上限"要比较的数。 |
| **低/高频 RMS：22.59 / 3.314 nm** | 比中频更缓、更大尺度的起伏是低频（22.59 nm），比中频更细、更小尺度的起伏是高频（3.314 nm）。低频大说明面形整体偏差大，适合扫描驻留修。 |
| **主导空间频率方向：5°** | 中频误差最明显的纹路朝向，5° 约等于沿水平方向。 |
| **ROI 索引：X[5:590]，Y[3:459]** | 检测区域在整幅数据里的位置，横向取第 5 到 590 列，纵向取第 3 到 459 行。ROI 是"感兴趣区域"的缩写。 |

低频 22.59 nm 比中频 8.80 nm 大，所以这块镜子的主要问题在低频，软件会建议先用扫描驻留。

这些词对大专生来说还是偏专业，建议把"检测区域""有效率"之外的几项换成更直白的叫法，并加个问号提示。比如：
- PV → 最大起伏
- RMS → 平均偏差
- 低频 / 中频 / 高频 → 大波纹 / 中波纹 / 细波纹
- ROI 索引 → 检测范围

要的话我来改，并在每一项旁边加悬停说明。
