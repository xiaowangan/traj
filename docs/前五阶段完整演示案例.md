# 完整演示：R2289.10 曲面 + 20 mm 抛光斑

> 照着点就行。每一步：**在哪 → 填什么 → 点什么 → 应该看到什么**。
> 数据都在 `data\examples\`。这是联调示例，采斑时长等是假设值，不是正式工艺。
> 2026-10-26 按新界面实际操作一遍核对过，数字来自那次操作。

启动：

```bash
conda run --no-capture-output -n proj python -B main.py
```

---

## 1. 导入工件（工艺流程 → 导入工件）

**期望曲面**（点顶部标签“期望曲面”）

| 填 | 值 |
|---|---|
| 口径类型 | 矩形，LX `296`，LY `230`，圆角 `0` |
| 面形类型 | 球面，R `2289.10` |
| 高级：案例计算网格（点开） | X `2`，Y `2` |

点 **生成曲面模型** → 点 **下一步：导入加工前实测面形**。

**实测面形**：点 **选择面形数据文件** → 选 `6S-320-250-FQZM-R2289.10-4#-0818-cgh-296-230.dat`（不带 N 前缀）。裁边、滤波都不用点。

✅ 应看到：PV `0.658`，RMS `0.0638`；回“总览”，三张卡片都是绿色“已完成”，对齐检查显示覆盖 `98.3%`、中心偏移 `0.42 mm`。

## 2. 面形初测（工艺流程 → 面形初测）

| 填 | 值 |
|---|---|
| 中频下限 / 上限 | `0.02` / `0.20` 周期/mm（波长框自动出现 `50` / `5` mm；反过来填波长，频率也会自动出现） |
| 高度单位 | 无需选择，统一为 nm（Zygo 数据按文件头波长 `632.8` nm 自动换算） |
| 加工目标 | 先全部留空 |

点 **计算检测结果**。

✅ 应看到：中频 RMS 约 `8.80 nm`，左侧四幅检测图。

## 3. 工艺资源（只需做一次，可被以后的案例复用）

**工艺资源 → 工具与设备**：抛光盘口径 `20`，转速 `60` → 点 **自动推荐压力和进给**。

**工艺资源 → 抛光斑/TIF**：点 **选择抛光斑文件** → 选 `spot_20_disk.dat`；采斑时长 `60` → 点 **计算去除函数**。

✅ 应看到：`9×9202` 去除核，脉冲 `0.467`。

## 4. 制定方案（工艺流程 → 制定方案）

1. **加工方式**：顶部有建议（本例建议扫描驻留）。保持“扫描驻留” → 点 **确定加工方式**。
2. **工具与贴合**：工具、口径已自动带入 → 点 **贴合检查**。✅ 最大间隙 `0.022 mm`，满足标准。
3. **抛光斑/TIF**：已显示 `9×9`，不用动。
4. **覆盖路径**：行间距 `4`，点间距 `4`，栅形、沿 X → 点 **轨迹预览**。
5. 点 **生成候选方案** → 点 **下一步：效果预估**。

## 5. 效果预估（自动进入）

| 填 | 值 |
|---|---|
| 检测区裁边 | `6`（轨迹区裁边 `0`） |
| 算法类型 | 最小二乘法 |
| 均抛厚度 / 最大驻留 / 最小驻留 | `0.05` / `120` / `0.02` |

点 **求解驻留时间**。

✅ 应看到：RMS `0.0561 → 0.00133`；达标判定显示中频 `8.88 → 0.50 nm`、“未设目标”。

点 **确认并冻结方案** → 点 **下一步：生成程序**。（不确认，执行页是锁住的。）

## 6. 生成程序（自动进入）

路径参数已从规划带入（只读），机床设置保持默认。

点 **表面轨迹生成** → **CNC 程序生成** → **保存 CNC 代码**。

✅ 应看到：`4161` 个轨迹点，CNC `4166` 行。

---

## 试一下“改了前面，后面自动失效”

回到 **评价**，把“中频 RMS 上限”填 `0.1`。

✅ 预测、执行的状态都变成橙色“已失效”，执行页重新锁住。回预测页重新 **求解驻留时间** → 判定“未达标”。这时点 **确认并冻结方案** 会要求写理由。

## 试一下共形振动分支

1. **评价**：“中频 RMS 上限”填 `2.2`（约为加工前的 1/4）。
2. **规划 → 加工方式**：选“共形振动” → **确定加工方式**；振动参数 β0 `0.004`，计划时长 `1500` → **生成候选方案** → **下一步：效果预估**。
3. **预测**：页面只剩共形振动的内容 → 点 **预测中频演化**。✅ `8.80 → 1.03 nm`，约 `852 s` 达标 → **确认并冻结方案**。
4. **执行**：提示“共形振动无需生成执行文件”，不用填任何参数。

## 保存 / 打开

**工具 → 保存案例** 存成 `.polcase`；**工具 → 打开案例** 恢复。轨迹和 CNC 不保存，打开后在执行页重新生成即可。**工具 → 新建案例** 清空重来。

## 数字对不上时

先查这四项：计算网格是不是 `2`、面形文件是不是不带 N 前缀、面形文件头能否读到测量波长 632.8 nm、采斑时长是不是 `60`。
也可以运行 `tests/test_ui_flow.py`，它用代码走一遍同样的步骤并核对数字。末位数字有轻微差异属正常。
