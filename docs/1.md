# 三个完整演示案例（扫描驻留）——给第一次用的人

> 这份文档带你把软件的“建档 → 评价 → 规划 → 预测 → 执行”五个阶段完整走三遍，每遍用一块不同的镜子：一块矩形球面、一块窄长平面、一块小圆球面。
> 三个案例**都只走“扫描驻留”这一条路**，不涉及共形振动。
> 每一步都写成：**在哪 → 填什么 → 点什么 → 应该看到什么 → 这一步在干嘛**。
>
> 数据文件都在 `data\examples\`。
> **所有数字都是 2026-10-30 用软件真实计算出来的**（案例一的数字与旧文档《前五阶段完整演示案例》完全一致，说明环境没问题）。
> 抛光斑的采斑时长、驻留上下限等都是**联调用的假设值，不是正式工艺参数**。

---

## 0. 先读这一节：你需要知道的几个词

| 词 | 白话 |
|---|---|
| **期望曲面** | 镜子**应该**长什么样的设计图（平面？球面？多大？）。 |
| **实测面形** | 干涉仪量出来的镜子**实际**长什么样。它是“误差图”：越接近 0 越好。 |
| **波长数（waves）** | 干涉仪文件里高度的单位。1 个波长 = 632.8 nm。所以“PV = 3 波”就是最高点和最低点差了约 1.9 微米。 |
| **PV / RMS** | PV = 最高减最低；RMS = 整体起伏的“平均大小”。越小越好。 |
| **低频 / 中频** | 按起伏“密不密”分：整体缓慢弯曲 = 低频；一圈圈细密波纹 = 中频。本软件的中频范围默认取 0.02～0.20 周期/mm（即波纹间距 5～50 mm）。 |
| **抛光斑 / TIF** | 抛光工具在原地磨一会儿留下的“小坑”。知道一秒能磨掉多少、坑多大，才能算出每个位置该停多久。**它的大小决定了你能修多细的波纹**（见第 2.7 节）。 |
| **驻留时间** | 工具在每个点停留多久。**停得久 = 磨得多**。扫描驻留就是用“该停多久”这张地图去修形。 |
| **扫描驻留** | 小工具沿着一条条平行的线走，误差大的地方多停，误差小的地方少停。 |
| **贴合检查** | 抛光盘是平的，镜面是弯的。盘越大、镜面越弯，盘边缘和镜面之间的缝越大，贴合越差。 |

**五个阶段**（软件顶部的五个图标，前一阶段做完才能做下一阶段）：

```
建档 ──→ 评价 ──→ 规划 ──→ 预测 ──→ 执行
 ①        ②       ③       ④       ⑤
 镜子是    现在有    用什么    加工完    生成机床
 什么、量  多不平、   方式、    会变成    能跑的
 出来什么  毛病在哪   走哪条线   什么样    程序
```

### 启动软件

```bash
conda run --no-capture-output -n proj python -B main.py
```

### 三个案例一眼看区别

| | 案例一 R2289.10 | 案例二 1A# 长条镜 | 案例三 D100 小圆镜 |
|---|---|---|---|
| 形状 | 矩形 296×230 mm | **窄长条** 380×57 mm（四角略圆） | **圆形** 直径 100 mm |
| 面形 | 球面 R=2289.10 | 平面 | 球面 R=100 |
| 加工前 PV | 0.658 波 | 3.19 波 | 0.366 波 |
| 抛光斑 | 20 mm 盘（`spot_20_disk.dat`） | **小斑**（`1300-145-0.3斑1.dat`，约 4.9×8.7 mm） | 同案例二的小斑 |

建议按顺序做：先案例一，再二、三。

## 1. 案例一：R2289.10 球面（标准流程）

文件：`6S-320-250-FQZM-R2289.10-4#-0818-cgh-296-230.dat`（**不带 N 前缀的那个**）。
文件名里 296-230 是口径尺寸，R2289.10 是球面半径，建模时直接抄。

### 1.1 建档（工艺流程 → 建档）

**① 期望曲面**（点顶部标签“期望曲面”）——告诉软件镜子设计成什么样。

| 填 | 值 |
|---|---|
| 口径类型 | 矩形，LX `296`，LY `230`，圆角 `0` |
| 面形类型 | 球面，R `2289.10` |
| 高级：案例计算网格（点开） | X `2`，Y `2` |

> “计算网格 2 mm”：软件算驻留时间时，每隔 2 mm 取一个点。取得太密会很慢，太疏会丢细节。

点 **生成曲面模型** → ✅ “曲面模型生成完成：17135 个有效节点”。点 **下一步：导入加工前实测面形**。

**② 实测面形**：点 **选择面形数据文件** → 选上面那个文件。裁边、滤波都不用点。

✅ 应看到：
- “面形已读取：149×117，PV=0.65842，RMS=0.0638267”，并提示“文件头测量波长 632.8 nm”；
- 回到“总览”，三张卡片都是绿色“已完成”；
- **对齐检查通过：覆盖 98.3%，中心偏移 0.42 mm**。

> **对齐检查是干嘛的？** 把“你填的设计口径”和“实测数据的有效范围”叠在一起比：数据有没有盖住设计口径、中心偏了多少。绿色 = 对得上；黄色 = 有问题，**先别往下走**，去查口径是不是填错了。

### 1.2 评价（工艺流程 → 评价）

| 填 | 值 |
|---|---|
| 中频下限 / 上限 | `0.02` / `0.20` |
| 高度单位 | **Zygo 波长数**（波长自动填 `632.8`） |
| 加工目标 | 先全部留空 |

点 **计算评价结果**。

> **为什么一定要选“Zygo 波长数”？** 数据文件里存的是“波长数”，不是纳米。软件**不会替你猜**单位；不选的话结果都是“原数值”，和纳米没法比，页面会有“高度单位未确认”的警告。

✅ 应看到：区域 PV=415.28 nm，RMS=39.802 nm；**低频 RMS=22.594，中频 RMS=8.804，高频 RMS=3.314 nm**；左侧四幅评价图。软件建议“扫描驻留（修低频面形）”——低频（22.6）比中频（8.8）大，优先处理大的。

> **这一步在干嘛？** 把误差拆成“整体歪”“细波纹”“更细的毛刺”三份，告诉你毛病主要出在哪。

### 1.3 工艺资源（工艺资源 → 工具与设备、抛光斑/TIF）

**工具与设备**：抛光盘口径 `20`，转速 `60` → 点 **自动推荐压力和进给** → ✅ 压力 `8.792`，进给 `60`，材料“聚氨酯”。

**抛光斑/TIF**：点 **选择抛光斑文件** → 选 `spot_20_disk.dat`；采斑时长 `60` → 点 **计算去除函数**。

✅ 应看到：`9×9` 的去除核，脉冲 `0.467`。

> **这一步在干嘛？** 告诉软件“我的工具是直径 20 mm 的盘，原地磨 60 秒会留下这么一个坑”。后面算驻留时间全靠这个“坑”。`spot_20_disk.dat` 是演示用的现成数据。

### 1.4 规划（工艺流程 → 规划）

1. **加工方式**：保持“扫描驻留” → **确定加工方式**。
2. **工具与贴合**：工具、口径已自动带入 → **贴合检查**。✅ **最大间隙 0.0218 mm，满足标准**（参考标准 ≤ 0.05 mm）。
3. **抛光斑/TIF**：显示 `9×9`，不用动。
4. **覆盖路径**：行间距 `4`，点间距 `4`，栅形、沿 X → **轨迹预览**。✅ 57 条线段，4275 个采样点。
5. **生成候选方案** → **下一步：预测**。

> **贴合间隙怎么来的？** 缝隙 ≈ 盘半径² ÷ (2×镜面半径) = 10² ÷ (2×2289) ≈ 0.022 mm。**盘越大、镜面越弯（R 越小），缝越大**。案例三会用到这个公式。
> **行间距 4 / 点间距 4？** 工具一行一行走，行与行相隔 4 mm；每行上每 4 mm 取一个点。盘直径 20 mm，行距 4 mm，相邻行叠盖很多，磨得均匀。

### 1.5 预测

| 填 | 值 |
|---|---|
| 评价区裁边 | `6`（轨迹区裁边 `0`） |
| 算法类型 | 最小二乘法 |
| 均抛厚度 / 最大驻留 / 最小驻留 | `0.05` / `120` / `0.02` |

点 **求解驻留时间**。

✅ 应看到：
- **RMS `0.0561 → 0.00133`**（波长数；是去掉边缘 6 mm 之后的评价区内的值）；
- **中频 `8.88 → 0.50 nm`**，判定“未设目标”。

点 **确认并冻结方案** → **下一步：执行**。（不确认，执行页是锁住的。）

> **三个参数？** 均抛厚度：整面再统一多磨一层，避免“某处完全不磨”这种做不到的要求；最大驻留 120 s：任何一点最多停 120 秒；最小驻留 0.02 s：低于这个按 0。
> **“确认并冻结”？** 相当于“我认了这个方案”。认了之后前面任何参数再改，这里会变成橙色“已失效”，提醒你重算，避免“新数据配旧结果”。
> **预测可信吗？** 它只是“工具按固定去除函数一刀刀磨”的理想计算，**没有经过实验验证**，软件会用黄字提醒。

### 1.6 执行

路径参数已从规划带入（只读），机床设置保持默认。点 **表面轨迹生成** → **CNC 程序生成** → **保存 CNC 代码**。

✅ 应看到：**4161 个轨迹点，CNC 4166 行**；驻留总时间约 18319 s（≈ 5.1 小时），单点最长约 4.8 s。

> 最后得到的 `.path` 文件就是给机床的“路线 + 每个点停多久”。

## 2. 案例二：1A# 窄长条镜（换小抛光斑）

文件：`1A#-ZJFS-M1-SN2-0324-cgh.dat`

**先说明哪些是我推断的**：文件名里没有口径和面形信息。我从数据本身读出：有效区域 **380.5 × 57 mm**，是个四角略圆的长方形；去掉倾斜后仍有 PV 3.2 波的误差，说明它是一份“误差图”。所以本案例**假设它是平面镜**，四角圆角半径取 **12 mm**（由四角被削掉的大小估的）。如果你知道真实设计值，请改成真实值。

**这个案例我先后试了两种抛光斑**：用案例一的 20 mm 大斑，中频只能降一小部分；换成小斑后中频几乎全部修掉。下面正文走“小斑”这条路，对比放在 2.7 节。

### 2.1 建档

**① 期望曲面**

| 填 | 值 |
|---|---|
| 口径类型 | 矩形，LX `380`，LY `57`，圆角 `12` |
| 面形类型 | **平面**（不用填 R，软件提示“平面无需面形参数”） |
| 高级：案例计算网格 | X `1`，Y `1`（**注意这次是 1，不是 2**） |

> **为什么网格改成 1？** 镜子只有 57 mm 宽，网格 2 mm 时只有约 30 行，太粗；而且小抛光斑只有几毫米大，网格也必须跟着变细，否则表示不出这个斑。

点 **生成曲面模型** → ✅ “曲面模型生成完成：21569 个有效节点”。点 **下一步**。

**② 实测面形**：选 `1A#-ZJFS-M1-SN2-0324-cgh.dat`。

✅ 应看到：
- “面形已读取：**383×59**，PV=**3.19367**，RMS=**0.48719**”；
- **对齐检查通过：覆盖 97.3%，中心偏移 0.514 mm**。

> **PV 3.19 波**（约 2 µm），比案例一大 5 倍，加工量会明显更大。

### 2.2 评价

填法与案例一完全一样：中频 `0.02` / `0.20`，高度单位选“Zygo 波长数”，目标留空 → **计算评价结果**。

✅ 应看到：
- 区域 PV = **1793.6 nm**，RMS = **218.61 nm**；
- 低频 RMS = **50.27**，**中频 RMS = 52.62**，高频 RMS = 3.83 nm；
- 黄字：“最低可分辨频率约 0.0198 周期/mm（所选下限低于分辨能力）”。

> **软件这次建议“共形振动（平滑中频）”**，因为中频（52.6）比低频（50.3）略大。**本案例按要求走扫描驻留**，到规划页仍选“扫描驻留”。软件只是建议，决定权在你。
> **“最低可分辨频率”那条黄字？** 镜子只有 57 mm 宽，装不下间距 50 mm 的波，所以中频范围最低端的结论不太可靠。记一下就行，不用处理。

### 2.3 工艺资源（这次换成小斑）

**工具与设备**：抛光盘口径 `5`，转速 `60` → 点 **自动推荐压力和进给** → ✅ 压力 `0.5495`，进给 `15`。
**抛光斑/TIF**：选 **`1300-145-0.3斑1.dat`**；采斑时长 `60` → **计算去除函数**。
✅ 应看到：**`9×5`** 的去除核（X 方向 5 格、Y 方向 9 格，即约 4.9 × 8.7 mm 的椭圆小斑），脉冲 `0.0840`。

> **脉冲 0.084 对比案例一的 0.467，小了 5.6 倍**：小斑每秒磨得少。这是“换小斑”的代价，后面时间会变长。
> 盘口径 5 mm 是我按小斑的大小取的演示值（斑最窄处约 4.9 mm）。采斑时长 60 s 仍是假设。

### 2.4 规划

1. **加工方式**：此时建议是共形振动。**手动保持/选择“扫描驻留”** → **确定加工方式**。
2. **工具与贴合** → **贴合检查**。✅ **最大间隙 0 mm**，满足标准。（平面，盘多大都贴得严。）
3. 抛光斑显示 `9×5`，不动。
4. **覆盖路径**：行间距 `4`，点间距 `4`，栅形、沿 X → **轨迹预览**。✅ **14 条线段，1330 个采样点**。
5. **生成候选方案** → **下一步：预测**。

> 14 条线：57 mm 宽 ÷ 行距 4 mm ≈ 14。工具沿 380 mm 的长边来回走 14 趟。

### 2.5 预测

参数与案例一完全一样（评价区裁边 `6`；最小二乘法；均抛 `0.05` / 最大 `120` / 最小 `0.02`）→ **求解驻留时间**。

✅ 应看到：
- **RMS `0.2488 → 0.00166`**（波长数）；
- **中频 RMS：`72.86 → 0.034 nm`**（预测后），“未设加工目标”。

点 **确认并冻结方案** → **下一步：执行**。

> **为什么这里中频是 72.86，评价页是 52.62？** 评价页用的是**原始测量网格（0.5 mm 一格）**，预测页用的是**案例计算网格（1 mm 一格）**。两个数不能互相比，**同一页内的“前→后”才能比**。
> **0.034 nm 是不是太好了？** 是。这是理想卷积模型的结果，假设斑形状完全准确、机床完全按图走。真实加工做不到这么好，别当结论。

### 2.6 执行

点 **表面轨迹生成** → **CNC 程序生成** → **保存 CNC 代码**。
✅ 应看到：**1313 个轨迹点，CNC 1318 行**。
驻留总时间约 **200804 s ≈ 55.8 小时**，单点最长约 50 s（未超过 120 s 上限），没有点被卡在上限。

> **55.8 小时，是不是太长？** 是，这是小斑的代价（见 2.7）。用大斑只需约 2.3 小时但修不动中频。实际工作里需要在“修得干净”和“时间可接受”之间取舍：可以先用大斑修低频，再换小斑修中频。（这只是思路，本文没有演示。）

### 2.7 为什么用 20 mm 大斑，中频只降了一点？

**是的，就是抛光斑太大。** 我把同一块镜子分别用两种斑跑了一遍（网格都是 1 mm，其他参数完全一致）：

| | 20 mm 大斑 | 小斑（约 4.9×8.7 mm） |
|---|---|---|
| 预测 RMS（波长数） | 0.2488 → 0.0934 | 0.2488 → **0.00166** |
| 预测中频 RMS（nm） | 72.86 → **15.7** | 72.86 → **0.034** |
| 驻留总时间 | ≈ 2.3 小时 | ≈ 55.8 小时 |

**原因（一句话）：工具磨不出比自己小的细节。** 工具的去除斑就像一支“笔”，笔头比波纹还粗，就写不出这么细的字。用数学的话说，抛光斑对不同间距的波纹有一个“修得动的比例”（我直接对两个斑的数据做傅里叶变换算出来的）：

| 波纹间距（对应频率） | 20 mm 大斑能修的比例 | 小斑能修的比例（X 方向 / Y 方向） |
|---|---|---|
| 50 mm（0.02 周期/mm） | 约 68% | 约 99% / 97% |
| 20 mm（0.05） | **约 14%** | 约 93% / 83% |
| 10 mm（0.1） | **约 15%** | 约 75% / 49% |
| 5 mm（0.2） | 约 4%～8% | 约 24% / 18% |

看第二行：间距 20 mm 的波纹，20 mm 的大斑只能修掉 14%；小斑能修掉 80% 以上。而本案例的中频范围是 5～50 mm，绝大部分落在大斑修不动的区域，所以中频剩了一大截。

> **所以案例一为什么没这个问题？** 案例一中频本来就小（8.8 nm），低频才是主要问题（22.6 nm），大斑修低频刚刚好。案例二的中频反而是主要问题，就需要小斑。
> **选斑的经验：** 想修多细的波纹，斑的尺寸就要比这个波纹间距小得多。先看评价页是低频大还是中频大，再选工具。
> 这里“预测”的前提都是理想的，**真实的修正能力会比表里差**，表只用来比较相对差别。

## 3. 案例三：D100-R100 小圆镜（小镜子，用小盘）

文件：`D100-R100-1H-1029.dat`
**文件名推断**：D100 = 直径 100 mm，R100 = 球面半径 100 mm，1H 可能是第一次测量/第一小时（不确定）。数据实际有效直径约 98 mm，对齐检查能通过，所以这个读法大概率没错；真实设计值请以图纸为准。

> **为什么选这块圆镜？** 我试了 `data\examples` 里所有圆形的文件：D90-R229 的 PV 达 22 波、D470 达 10 波、D100-R100-2H 达 18 波，误差都太大，不适合演示；只有这块 PV 才 0.37 波，和案例一量级相当，且口径完全对得上。

### 3.1 建档

**① 期望曲面**

| 填 | 值 |
|---|---|

### 3.3 工艺资源

### 3.4 规划

1. **加工方式**：选“扫描驻留” → **确定加工方式**。
2. **工具与贴合** → **贴合检查**。✅ **最大间隙 0.0313 mm，满足标准**。
   > 套公式：盘半径 2.5 mm → 2.5² ÷ (2×100) ≈ 0.031 mm。**如果沿用案例一的 20 mm 盘**：10² ÷ 200 = **0.5 mm**，超标 10 倍，贴不上。曲率这么大（R=100）的小镜子只能用很小的盘，这就是第 1 节说的“盘越大、镜面越弯，缝越大”。

## 5. 通用小技巧

### 改了前面，后面自动失效
在**评价**页把“中频 RMS 上限”改个数，**预测、执行**会变成橙色“已失效”，执行页重新锁住。回预测页重新求解即可；若判定“未达标”，点“确认并冻结方案”会要求写理由。

### 保存 / 打开
**工具 → 保存案例** 存成 `.polcase`；**工具 → 打开案例** 恢复。轨迹和 CNC 不保存，打开后在执行页重新生成。**工具 → 新建案例** 清空重来。换案例前建议先“新建案例”，避免上一个案例的残留（尤其是抛光斑和计算网格）。

### 数字对不上时
先查这五项：
1. **计算网格**：案例一是 `2`，案例二、三是 `1`；
2. **面形文件**选对了没（案例一是**不带 N 前缀**的）；
3. **高度单位**是不是“Zygo 波长数”；
4. **抛光斑文件、采斑时长 60、盘口径**（案例一 `spot_20_disk.dat` / 盘 20；案例二、三 `1300-145-0.3斑1.dat` / 盘 5）；
5. 案例二的圆角 `12`、案例三的外径 `100` 和 R `100` 填对没。

末位数字有轻微差异属正常。

### 本文的局限
- 案例二的“平面”“圆角 12”、案例三的“D100 / R100 含义”是我根据文件名和数据推断的，不是图纸给的；
- 抛光斑 `1300-145-0.3斑1.dat` 的真实工具、采斑时长是不确定的，这里按 60 s 假设；盘口径 5 mm 也是演示值；
- 所有“预测”只是理想卷积模型，**没有经过实验验证**，不能当作加工后的实际结果；
- 案例二用小斑 55.8 小时是在上述假设下的结果，换一个采斑时长会成比例变化。
